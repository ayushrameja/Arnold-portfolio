Cloudflare hosting migration

Use Node 24 and pnpm 12.4.1.
Install: pnpm install --frozen-lockfile
Build: pnpm run build:cloudflare
Local Workers runtime: pnpm run preview:cloudflare
Deploy built preview: pnpm run deploy:preview

The Wrangler configuration deploys a separate migration-preview Worker without custom-domain routes. Merging this change does not move production domains. Existing Vercel production stays available for rollback. Git-triggered Cloudflare deployments and production domain attachment will be configured after review/merge.

Cloudflare runtime requires SMTP_EMAIL, SMTP_PASSWORD and CONTACT_EMAIL. Set these with Wrangler secrets or the dashboard; never commit them. Preserve the existing recipient settings. Secrets are configured separately from the repository. Email delivery testing sends a real message and must use an explicitly approved test.

Validation on 17 October 2026: Next/OpenNext build and deployed Workers routes passed; generated assets served successfully. Contact/backend delivery evidence is recorded in the migration handoff. No Vercel cleanup or DNS cutover is authorized by merging this PR alone.
